#### 🔭 Selected work

**[HomoDeus](https://github.com/gupessanha/AI-Engineer-Challange---HomoDeus)** — *AI Engineering · Empirical evaluation*
Conversational agent for Portuguese labor law and payroll, built in <48h
for a technical challenge. Gemini 2.5 Pro with function calling, hybrid
retrieval (local BM25 over the 615-article Labor Code + Tavily restricted
to T1/T2 official sources), tier-classified citations. The eval is
designed as a controlled experiment: prompt-hashed runs across 12 cases,
calibrated Flash judge, decomposition into three runs to isolate prompt
effect vs. model effect (≈+17 pp behavioral from prompt, ≈+8 pp factual
from model, no regression). Documented in three languages with a full
DESIGN_DECISIONS log (D1–D11).

**[skate_data_fusion](https://github.com/gupessanha/skate_data_fusion)** — *Signal processing & ML*
Inertial sensor fusion pipeline for classifying skate tricks. Gyro bias
calibration via least squares, fuzzy pose classification across six
static stances, accel + gyro complementary filter (α=0.98). Research
prototype, with a full retrospective in the README on what I'd change today.

**FUNASA** *(undergraduate research, private)* — *Mobile / Flutter*
Mobile frontend for a system commissioned by Brazil's National Health
Foundation. Working under a research scholarship at UFRJ.

**NEUROSENSES** *(undergraduate research, private)* — *Neurotech / ML*
Non-invasive brain mapping and real-time emotion classification, with
applications in marketing, consumer experience, and wellbeing research.

**[locadora-dw-parte1](https://github.com/gupessanha/locadora-dw-parte1)** — *Data warehousing*
